Multi-Threaded Network Monitoring Tool

A Python-based cybersecurity network application designed to simulate network traffic and monitor data packet interception.

Features:
1. Simulated IDS: Monitors local transport layer (UDP) traffic on port 9999.
2. Traffic Generator: Simulates network logs/malicious payload generation.
3. Multi-Threaded Engine: Runs both packet generation and sniffing simultaneously.
4. Cross-Platform: Runs seamlessly on restricted environments like non-rooted Android OS (Pydroid 3) and standard PCs.
